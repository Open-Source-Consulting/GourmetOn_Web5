INTEGRANTE 2 — 0:35 A 1:20
FETCH, API E JSON
======================================================================

NA TELA
Abrir mealApi.js e apontar API_URL, request(), getCategories(),
getMealsByCategory() e getMealById().

FALA
“Centralizamos as requisições na função request, que usa fetch e
async/await. Ela verifica response.ok, lança um erro se a resposta
HTTP falhar e depois lê o JSON com response.json().

Primeiro, getCategories consulta list.php?c=list para obter todas
as categorias. Depois, getMealsByCategory usa filter.php?c= e
slice para retornar até cinco pratos de cada categoria.

A função getMealsGroupedByCategory usa Promise.all para fazer essas
consultas em paralelo e organizar os pratos em grupos. Como essa rota
retorna dados resumidos, getMealById consulta lookup.php?i= quando
precisamos dos ingredientes e das outras informações completas.”

TRECHOS
export async function getCategories() {
  const data = await request("list.php?c=list");
  return (data.meals ?? []).map((item) => item.strCategory);
}

return (data.meals ?? []).slice(0, limit);

3. Voltar a “Todos”.

FALA
“As categorias agora vêm diretamente da API. Cada grupo possui o nome
da categoria e até cinco pratos.

O filtro é feito localmente sobre esses grupos. Quando selecionamos
‘Todos’, mostramos todas as categorias. Quando escolhemos uma categoria,
mostramos somente o grupo correspondente, sem fazer outra requisição
para trocar o filtro.

Ao clicar em ‘Ver detalhes’, enviamos o ID para abrirDetalhes. Essa
função busca os dados completos do prato e os guarda em
pratoSelecionado. Enquanto isso, o botão mostra ‘Carregando...’ e
fica temporariamente desabilitado.”

TRECHOS
const gruposVisiveis =
  categoria === "Todos"
    ? pratosPorCategoria
    : pratosPorCategoria.filter(
        (grupo) => grupo.category === categoria

MODAL, INGREDIENTES E ENCERRAMENTO
======================================================================

NA TELA
Com o modal aberto, mostrar os dados do prato.
Abrir MealDetails.jsx: referência ao dialog e laço dos ingredientes.
Voltar ao navegador, fechar com Esc e confirmar o filtro preservado.

FALA
“Depois da busca dos dados completos pelo ID, o MealDetails recebe o
prato pela prop meal. Ele usa o dialog nativo, aberto com showModal
por uma referência criada com useRef. Isso permite usar o controle de
foco e o fechamento por Esc do navegador, sem biblioteca adicional.

Os ingredientes vêm em campos separados, de strIngredient1 até
strIngredient20. Percorremos esses campos com um for e ignoramos
os vazios. O modal mostra nome, origem, categoria e os ingredientes
informados pela API.

A rolagem fica dentro do modal, e a limpeza do efeito libera o fundo
ao fechar. Fechar o modal não altera a categoria selecionada. O
formulário e o download são demonstrativos. Para o deploy na Vercel,
usamos o build padrão do Vite.”

TRECHO
for (let i = 1; i <= 20; i++) {
  const ingredient = meal[`strIngredient${i}`];

  if (ingredient && ingredient.trim()) {
    ingredients.push(<li key={i}>{ingredient}</li>);
  }
}
